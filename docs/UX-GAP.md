# UX 差距清单（对照滴答清单）

> 目标：交互与移动端体验向原版 1:1 靠拢。  
> 范围：P0 交互债；功能模块（日历视觉大改 / P2）不在此列。  
> 更新日期：2026-10-10

## 低操作负担原则

1. **拇指优先**：关键操作落在单手可达区（底栏、列表滑动、FAB），少逼用户伸到屏幕顶角。
2. **一步完成**：完成 / 改期 / 删除不先点进详情；滑动或勾选即可，并支持撤销。
3. **即时反馈**：操作后 Toast / 轻动画确认；危险操作可撤销（约 5s），少弹确认框。
4. **少模式切换**：同一清单内列表 ↔ 看板 ↔ 日历切换成本要低；详情尽量半屏，不整页打断。
5. **尊重硬件**：刘海 / 状态栏 / Home 指示条用 `safe-area-inset-*`；触控目标 ≥ 44px。
6. **可配置但有默认**：滑动手势等应对齐滴答默认，高级自定义后置。

## 验证备忘

- **安全区**：Chrome 设备工具栏选 iPhone；或 Android WebView 刘海机；顶栏/底 Toast / 底栏不应贴死物理边缘。  
- **滑动**：宽度 &lt; 768px 时右滑完成/置顶，左滑今天/明天/移动/删除；完成后 Toast 可撤销。  
- **底栏**：窄屏底部五 Tab（任务/习惯/日历/四象限/更多）切换；「更多」开侧栏；宽屏无底栏、仍三栏侧栏。  
- **详情**：窄屏点任务出半屏 Sheet，可上拉近全屏；宽屏右侧详情栏。  
- **FAB**：窄屏右下「+」可拖、松手贴边；点击快速添加；宽屏无 FAB。  
- **桌面**：≥768px 无滑动条，hover 行右侧有置顶/删除。  
- **同步**：未改 Cloudflare Worker / Access Key 协议；仅本地 `pinned` 字段随任务 JSON 同步。
